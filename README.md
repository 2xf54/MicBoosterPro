# MicBoosterPro (iOS Microphone Amplifier & Saturation)

تطبيق احترافي للآيفون لتضخيم صوت المايكروفون (Preamp Gain) مع تشويش ناعم (Analog Saturation) وفلتر حدة الصوت (Pierce High-Shelf).

---

## ⚡ المميزات:
1. **Preamp Gain (التضخيم العالي):** مضاعفة رقمية تصل إلى +45dB (أعلى بكثير من البرامج العادية).
2. **Distortion / Overdrive (التشويش والخشونة):** محاكاة تضخيم الصمامات التناظرية (Soft-Clipping Saturation) تعطي الصوت خشونة وثقل بدون تشويه سيء.
3. **Pierce / High-Shelf EQ:** فلتر رفع ترددات الحضور (3.5kHz) لجعل الصوت يخترق المكالمة ويكون واضحاً وحاداً.
4. **Hardware Input Boost:** ضبط حساس لاقط المايك الفيزيائي على أقصى حساسية (100%).
5. **Background Audio:** استمرار عمل المعالجة في الخلفية مع مكالمات التيليجرام وغيرها.
6. **سيتات جاهزة (Presets):** التبديل بنقرة زر بين Clean Loud، Piercing Boost، Overdrive Fuzz، و MAX CHAOS.

## 🚀 طريقة استخراج ملف الـ IPA وتثبيته عبر AltStore:

### الخطوة 1: رفع المشروع على GitHub
من جهاز الكمبيوتر الخاص بك، افتح سطر الأوامر (Terminal أو PowerShell) داخل مجلد `MicBoosterPro`:
```bash
git init
git add .
git commit -m "Initial commit for MicBoosterPro"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/MicBoosterPro.git
git push -u origin main
```
*(استبدل الرابط برابط مستودعك الجديد في GitHub)*

---

### الخطوة 2: تحميل ملف الـ IPA
1. افتح صفحة المستودع على **GitHub**.
2. اضغط على تبويب **Actions** في الأعلى.
3. ستجد مهمة **Build iOS IPA** تعمل تلقائياً (تأخذ حوالي دقيقة إلى دقيقتين).
4. عند انتهائها بعلامة خضراء ✅، اضغط عليها وانزل لأسفل الصفحة تحت قسم **Artifacts**.
5. ستجد ملف باسم **`MicBoosterPro-IPA`**، حمله وفك الضغط عنه لتحصل على ملف `MicBoosterPro.ipa`.

---

### الخطوة 3: التثبيت في الآيفون بـ AltStore
1. أرسل ملف `MicBoosterPro.ipa` إلى الآيفون (عبر التليجرام، الآيردروب، أو جوجل درايف).
2. افتح تطبيق **AltStore** في الآيفون.
3. ادخل على تبويب **My Apps** واضغط على علامة الزائد **(+)** في الزاوية.
4. اختر ملف `MicBoosterPro.ipa`.
5. سيقوم AltStore بتوقيع التطبيق وتثبيته على شاشة جوالك مباشرة!
